# burioworks — Brand Quick Guide

## Master
Use `reference/approved-green-B-master.png` as the visual source of truth.

## Brand name
`burioworks`

Do not capitalize it as `Burioworks` in brand-facing copy.

## Approved palette

| Token | Hex |
|---|---|
| Primary 700 | `#0F766E` |
| Primary 500 | `#14B8A6` |
| Primary 400 | `#2DD4BF` |
| Primary 200 | `#99F6E4` |
| Primary 050 | `#E6FAF8` |
| Ink | `#13223A` |

## Logo treatment
- Keep the approved proportions.
- Keep the approved polygon structure.
- Keep the mark flat.
- No extra facets.
- No gradients, bevels, glows, or shadows.
- No rotation or distortion.

## Minimum-size guidance
The approved master is a raster reference. At favicon sizes, use the provided exports and visually
check at 16 px and 32 px in the target browser/OS.

## Typography
The approved concept uses a clean modern sans-serif treatment.
Inter / Inter Display is the recommended implementation family for the website.
Font files are not included in this kit.
